## Описание

Макет страницы дополнен одномерной раскладкой на Flexbox, двумерной сеткой на CSS Grid и адаптацией под планшеты и мобильные устройства.

## Flexbox

- Навигационное меню `nav` — горизонтальное, с переносом пунктов при нехватке места
- Карточки «Фирменные блюда» — три штуки в ряд через `flex: 1 1 280px`
- Внутри карточки `flex-direction: column` выравнивает содержимое по вертикали

## CSS Grid

Галерея «Ингредиенты недели» — сетка 3×2 через `grid-template-columns: repeat(3, 1fr)`.

## Адаптивность

| Ширина экрана | Карточки | Сетка |
|---|---|---|
| от 900px | 3 в ряд | 3 колонки |
| 600–900px | 2 в ряд | 2 колонки |
| до 600px | 1 в ряд | 1 колонка |

На мобильных меню становится вертикальным. Горизонтальная прокрутка исключена правилом `img { max-width: 100% }`.

## Семантика и доступность

- Карточки размечены тегом `<article>` как самодостаточные блоки
- Пара «Время / ккал» оформлена списком определений `<dl>` / `<dt>` / `<dd>`
- Контрастность текста к фону не ниже 4.5:1

## Структура

- `index.html` — разметка страницы
- `style.css` — внешние стили
- `images/` — фотографии блюд и ингредиентов
